# Recommended Onboard Spare Parts List

## Essential Spares — Every Boat

### Engine
- [ ] Raw water impeller (spare for your specific engine)
- [ ] Alternator / fan belt (correct size)
- [ ] Fuel filters — primary & secondary (at least 2 of each)
- [ ] Engine oil — 2 litres (correct grade)
- [ ] Coolant — 1 litre concentrated
- [ ] Thermostat (correct temperature rating)
- [ ] Zincs (sacrificial anodes — hull, shaft, trim tabs)
- [ ] Impeller tool / puller

### Electrical
- [ ] Fuse assortment (all sizes used on boat: 5A, 10A, 15A, 20A, 30A, 40A)
- [ ] Wire connectors (butt, ring, blade — waterproof marine grade)
- [ ] 3m × 10mm² spare cable
- [ ] Electrical tape (self-amalgamating type)
- [ ] Multimeter (essential for any fault diagnosis)
- [ ] Spare navigation light bulbs (or LED equivalents)
- [ ] Spare VHF handheld (charged)

### Plumbing
- [ ] Hose clamps (assorted sizes)
- [ ] Short piece of hose (same diameter as thickest hose aboard)
- [ ] Through-hull bung (wood, tapered — one per through-hull)
- [ ] Underwater epoxy putty (West System, for emergency plugging)
- [ ] Duct tape
- [ ] Silicone sealant (marine grade)

### Rigging (Sailing Yachts)
- [ ] Spare halyard (same length as main halyard)
- [ ] Shackles — assorted (3 sizes)
- [ ] Rigging tape (for chafe protection)
- [ ] Clevis pins + cotter pins (2 of each)
- [ ] Bulldog clips / wire clamps (for emergency shroud repair)
- [ ] Spare sheets and dock lines

---

## Nice-to-Have Spares

- [ ] Spare prop (correct pitch for motor)
- [ ] Spare bilge pump float switch
- [ ] Spare windlass solenoid (if older windlass)
- [ ] Spare anchor light LED
- [ ] Start capacitor for windlass motor (Maxwell STD series)
- [ ] Marine silicone spray (lubricant for all seals, furlers)
- [ ] McLube sailkote (for furlers, track, slides)

---

## Outboard Specific (Gliseri / RIBovi)

- [ ] Spark plugs (one per cylinder)
- [ ] Water pump impeller kit (outboard specific)
- [ ] Fuel primer bulb + fuel line fitting
- [ ] Shear pin (correct size) or spare prop with spline hub
- [ ] 2-stroke oil (correct grade) or 4-stroke oil
- [ ] Kill switch lanyard
- [ ] Propeller socket wrench

## Tool Kit Minimum

| Tool | Use |
|---|---|
| Adjustable wrench 10" | General fasteners |
| Combination spanners 10–22mm | Engine work |
| Flathead screwdrivers (3 sizes) | Terminals, panels |
| Phillips screwdrivers (2 sizes) | Almost everything |
| Hex key set (metric) | Winch fasteners, instruments |
| Vice-grip pliers | Emergency grip |
| Needle-nose pliers | Electrical, cotter pins |
| Hacksaw | Emergency cutting |
| Mallet (rubber) | Non-damaging strikes |
| Feeler gauge set | Spark plug gap |
| Impeller puller | Engine maintenance |
| Electrical multimeter | Fault diagnosis |

## Safety Equipment Checks (Annual)

- [ ] Flares in date (EU: 3 years from manufacture)
- [ ] Life raft service (within service date — usually 1 year)
- [ ] EPIRB battery + hydrostatic release in date
- [ ] PLB battery in date
- [ ] Life jackets + hydrostatic releases serviced
- [ ] Fire extinguishers charged (check pressure gauge)
- [ ] First aid kit stocked and in date
- [ ] SOLAS approved distress signals (if offshore)
