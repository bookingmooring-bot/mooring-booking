# Video Script Formats — Marketing Ad Video Skill

Detailed specifications for each video ad format, timing structures, and production best practices.

## Format Specifications

### 📱 Instagram/Facebook Reels (15-30s)

| Spec | Value |
|------|-------|
| Duration | 15-30 seconds (sweet spot: 20-25s) |
| Aspect Ratio | 9:16 (1080x1920 px) |
| Max File Size | 4 GB |
| Hook Timing | First 1-3 seconds CRITICAL |
| Safe Zone | Keep text 250px from top/bottom edges |
| Audio | Music + voiceover or text-only |

**Timing Structure (25s Reel):**

| Sekunda | Sekcija | Svrha |
|---------|---------|-------|
| 0-3 | 🪝 HOOK | Zaustavi skrolanje. Pitanje, šokantna činjenica, ili vizualni trigger |
| 3-8 | 📌 PROBLEM | Pojačaj bol. Pokaži problem koji rješavaš |
| 8-18 | ✅ RJEŠENJE | Pokaži proizvod/uslugu. Demo, benefiti, kako radi |
| 18-22 | 💪 SOCIAL PROOF | Brojke, kredibilitet, rezultati |
| 22-25 | 👉 CTA | Jasna akcija: "Registriraj se besplatno" |

**Best Practices:**
- UGC (User-Generated Content) stil ima 2-3x veći CTR od poliranih reklama
- Tekst overlay na svakom frame-u (70%+ gleda bez zvuka)
- Vertikalni format — nikad horizontal
- Brzi rezovi (2-3s po sceni)

### 📸 Instagram/Facebook Stories (15s)

| Spec | Value |
|------|-------|
| Duration | Max 15 seconds |
| Aspect Ratio | 9:16 (1080x1920 px) |
| Swipe-Up/Link | Available for ads |
| Hook Timing | First 1-2 seconds |

**Timing Structure (15s Story):**

| Sekunda | Sekcija | Svrha |
|---------|---------|-------|
| 0-2 | 🪝 HOOK | Brzo i direktno. Jedan jasan statement |
| 2-8 | 💡 PORUKA | Jedna ključna benefit ili ponuda |
| 8-12 | 📊 DOKAZ | Jedna statistika ili vizualni dokaz |
| 12-15 | 👉 CTA | "Swipe up" ili "Registriraj se" |

**Best Practices:**
- Jedan fokus po story — ne pokušavaj reći sve
- Veliki, čitljiv tekst (minimum 24px)
- Bright boje za kontrast
- Animirane sticker-like elemente

---

### 🖥️ In-Feed Video (30-60s)

| Spec | Value |
|------|-------|
| Duration | 30-60 seconds (sweet spot: 45s) |
| Aspect Ratio | 1:1 (1080x1080) ili 4:5 (1080x1350) |
| Auto-play | Muted by default |
| Hook Timing | First 3 seconds |

**Timing Structure (45s In-Feed):**

| Sekunda | Sekcija | Svrha |
|---------|---------|-------|
| 0-3 | 🪝 HOOK | Zaustavi skrolanje |
| 3-10 | 📌 PROBLEM | Detaljiraj bol i frustraciju |
| 10-25 | ✅ RJEŠENJE | Demo proizvoda, korak-po-korak, benefiti |
| 25-35 | 💪 DOKAZ | Brojke, testimonijali, results |
| 35-40 | 🎁 PONUDA | Specifična ponuda ili incentiv |
| 40-45 | 👉 CTA | Dupli CTA: tekst + voice |

**Best Practices:**
- Square (1:1) zauzima više screen prostora u feed-u
- Subtitles OBAVEZNI (autoplay je muted)
- Progress bar ili timer povećava watch-through rate
- Thumbnail je prvi frame — mora biti jak

### ▶️ YouTube Pre-Roll (6-15s)

| Spec | Value |
|------|-------|
| Duration | 6s (bumper, non-skip) ili 15s (skippable after 5s) |
| Aspect Ratio | 16:9 (1920x1080) |
| Skip Button | After 5 seconds (15s version) |
| Hook Timing | First 2 seconds |

**Timing Structure (15s Pre-Roll):**

| Sekunda | Sekcija | Svrha |
|---------|---------|-------|
| 0-2 | 🪝 HOOK | Branding + hook PRIJE skip buttona |
| 2-5 | 💡 CORE MSG | Ključna poruka dok ne mogu skip |
| 5-10 | ✅ BENEFITI | Za one koji nastave gledati |
| 10-15 | 👉 CTA + LOGO | Završni CTA sa URL-om |

**6s Bumper Structure:**

| Sekunda | Sekcija |
|---------|---------|
| 0-1 | Logo/Brand |
| 1-4 | Jedna poruka (max 8 riječi) |
| 4-6 | CTA + URL |

## Hook Library (First 3 Seconds)

### Hooks po tipu:

**❓ Pitanje-hook:**
- "Tvoj vez stoji prazan?"
- "What if your mooring could pay for itself?"
- "Koliko zarađuješ od svog veza? €0?"

**😱 Šok-hook:**
- "€5.000 godišnje. Od praznog veza."
- "Većina vlasnika vezova baca €5.000 svake sezone."
- "Your empty mooring could earn more than you think."

**🆕 Novost-hook:**
- "NOVO: Airbnb za vezove je stigao!"
- "Just launched: the first mooring marketplace."
- "Nova platforma — budi prvi!"

**📊 Statistika-hook:**
- "85% zarade ostaje tebi."
- "11 zemalja. 15 jezika. Jedan klik."
- "10 minuta do prvog listinga."

## UGC Style Guidelines

Za Meta reklame, UGC (user-generated content) stil ima značajno bolji CTR:

1. **Snimaj mobilnim** — ne profesionalnom kamerom
2. **Prirodno osvjetljenje** — sunce, more, autentično
3. **Govor u kameru** — "Moram vam pokazati ovo..."
4. **Bez poliranog intro-a** — odmah u sadržaj
5. **Tekst overlay** kao da korisnik sam napravio
6. **Vertikalni format** — uvijek 9:16
7. **Bez stock muzike** — trending zvukovi ili tihi voiceover
