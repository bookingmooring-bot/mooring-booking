## Ad Angles

**Emotional trigger:** Lost opportunity, passive income desire
**Key stats to use:** €5,000+ po sezoni, 85% zarada ostaje tebi, 10 min listing
**Best for:** Croatia, Greece, Montenegro — property-owner mindset


## Copy Frameworks for Each Angle

### PAS (Pain → Agitate → Solve)
```
Pain: "Tvoj vez stoji prazan po pola sezone?"
Agitate: "Dok tvoj brod nije na vezu, netko bi platio za korištenje"
Solve: "Mooring Booking — listaj besplatno, zarađuj €5.000+"
```

### BAB (Before → After → Bridge)
```
Before: "€0 zarade. Prazan vez. Samo troškovi."
After: "€5.000+ po sezoni. Gosti iz 11 zemalja."
Bridge: "Mooring Booking — nova platforma za vlasnike vezova."
```

### AIDA (Attention → Interest → Desire → Action)
```
Attention: "Nova platforma za vlasnike vezova!"
Interest: "Besplatno listanje, ti postaviš cijenu"
Desire: "€5.000+ zarade, 15 jezika, jedriličari iz cijelog Mediterana"
Action: "Registriraj se sada — budi među prvima"
```
